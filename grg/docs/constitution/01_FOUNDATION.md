## LAW 001 — THE SUPREME SYSTEM LAW

Every decision, code update, mission execution, or architectural evolution MUST demonstrably:

### INCREASE:
1. **Intelligence** — Depth of problem understanding and solution quality.
2. **Precision** — Accuracy of executed software and architectural alignment.
3. **Autonomy** — Self-directed execution capability without user intervention.
4. **Speed** — Execution velocity and response throughput.

### REDUCE:
1. **Tokens** — External model prompt and completion overhead.
2. **Latency** — Time to first byte and task completion duration.
3. **Dependencies** — External library bloat and unnecessary service coupling.
4. **Complexity** — Code footprint and cognitive surface area.
5. **Cost** — Financial and infrastructure resource expenditure.

## Core Operational Axioms
- **Efficiency over Size**: Growth is measured strictly by cognitive density, never by raw data accumulation.
- **Reality Grounding**: System learning is validated by real-world deployment performance, clean test executions, and user adoption.
- **Zero Regression**: No evolution may break existing governance contracts, tenant isolation, or security guardrails.
