# FÊNIX OS — OBSERVATION MODE & WORKFLOW LEARNING

## 1. Modo de Observação Contínua
Quando ativado pelo operador, o **Development Observer** captura a sequência de eventos de desenvolvimento:
`ABRIR PROJETO -> ABRIR ARQUIVO -> EDITAR -> TESTAR -> REALITY GATE -> COMMIT`

## 2. Extração Causal e Criação de Skills
1. **Identificação de Padrão**: Análise causal detecta ações repetitivas bem-sucedidas.
2. **Skill Candidate**: Formulação de pré-condições, ferramentas e etapas do DAG.
3. **Validação de Veracidade**: Teste automatizado com o Reality Enforcement Engine.
4. **Publicação**: A skill é gravada no `SkillRegistry` e disponibilizada para reutilização cross-project.
