# GRG Knowledge Architecture

Project Mirror and repo-intel provide structural project context; graph edges connect repositories, capabilities, projects and insights. Memory events retain evidence and confidence, while the Evolution Engine derives idempotent insights from real signals.

External knowledge must retain source, repository/document, version or commit, license/provenance, import date and purpose. Retrieval responses should return these citations to the user and never silently import external code.

Next implementation: complete a source-cited ingestion pipeline for repository, URL, document and media sources with durable chunks and graph relations.
