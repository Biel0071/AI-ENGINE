# GRG Evolution Roadmap

## Completed or operational

1. Unified runtime, mission/job persistence and local worker.
2. Agent/skill registries and governed execution.
3. Event stream, live UI and honest health/error states.
4. AI Platform gateway integration and real generation.
5. Evolution Engine with evidence-backed, idempotent learning cycles.

## Next prioritized increments

1. Canonical Tool Handler contract for native + MCP tools.
2. Source-cited project import and Codebase Memory graph.
3. Mission acceptance flow: one user instruction creates and runs a governed mission, then returns artifacts and Definition of Done.
4. Persisted agent handoffs and organization metrics.
5. Editable mission/flow canvas backed by the same DAG, never a visual-only graph.
6. Production adapters: Postgres, Redis, vector store, secrets and deployment health.

Each increment requires backend/runtime integration, persisted state, event visibility, focused tests and browser verification.
